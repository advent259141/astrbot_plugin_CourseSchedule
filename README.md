# 课程表插件 for AstrBot

这是一个为AstrBot设计的课程表插件，它可以帮助群组成员方便地管理和查询自己以及群友的课程安排。

## ✨ 功能特性

*   **多种绑定方式**：支持通过发送 `.ics` 日历文件或 **WakeUp课程表** 分享口令，将个人课表与QQ号绑定。
*   **日期课程查询**：查看本人或群友指定日期的完整课表。
*   **群友课程总览**：查看群里所有已绑定用户在指定日期和时间的课程状态（进行中 / 下一节），方便约饭、约游戏。
*   **上课排行**：查看本周、上周、下周或整个学期群友的上课时长和节数。
*   **智能状态显示**：自动判断课程是“进行中”还是“下一节”，并计算剩余/等待时间。
*   **高度定制化**：
    *   支持显示用户昵称，而非QQ号。
    *   为个人课表、群友课表和排行榜提供三种不同的、精心设计的渲染样式。
    *   自动处理时区，确保时间准确。
    *   **支持自定义字体**：只需将你喜欢的 `.ttf` 或 `.otf` 字体文件放入插件目录，即可自动应用。

## 📝 命令列表

| 命令 | 功能描述 |
| :--- | :--- |
| `/绑定课表` | 在群聊中发送此命令，然后根据提示发送你的 `.ics` 文件或 WakeUp 分享口令来绑定课表。 |
| `/查看课表 [日期]` | 不带日期时显示你今天接下来要上的课程；带日期时显示当天全部课程。日期支持 `YYYY-MM-DD`、`今天`、`明天`、`昨天`。 |
| `/查看课表 [日期 @群成员]` | 在群聊中查询指定日期的某位已绑定成员当天全部课程。只支持查询当前群中已绑定的成员。 |
| `/群友在上什么课 [日期 时间]` | 查看群内已绑定成员在指定日期和时间正在上的课或下一节课；日期支持 `YYYY-MM-DD`、`今天`、`明天`、`昨天`，时间格式为 `HH:MM`。无参数或只填日期时，以真实当前时刻计算课程状态和等待时间；只填日期仍查询指定日期内的课程。填写时间时按指定时刻计算，只填时间则使用当天日期。 |
| `/查看明日课表` | 兼容旧命令，显示你自己明天要上的课程。 |
| `/群友明天上什么课` | 兼容旧命令，显示群里所有成员明天要上的课程。 |
| `/全学期上课排行` | 统计当前绑定课表中的全学期课程，显示群友上课时长和节数排行。 |
| `/上周上课排行` | 显示上周群友上课时长和节数的排行榜。 |
| `/下周上课排行` | 显示下周群友上课时长和节数的排行榜。 |
| `/本周上课排行` | 兼容旧命令，显示本周群友上课时长和节数的排行榜。 |

### 日期与时间查询示例

* `/查看课表 2026-10-13`：查看本人 2026 年 10 月 13 日的全部课程。
* `/查看课表 明天`：查看本人明天的全部课程。
* `/查看课表 2026-10-13 @小明`：在群聊中查看已绑定成员“小明”当天的全部课程。
* `/群友在上什么课 2026-10-13 14:30`：查看群友在 2026 年 10 月 13 日 14:30 正在上的课或接下来要上的课。
* `/群友在上什么课 14:30`：按当天 14:30 查询群友课程。

个人 `/查看课表` 不带日期时仍只显示今天接下来要开始的课程；显式传入日期后会显示该日全部课程。群友查询未填时间时，以真实当前时刻计算“进行中”与“下一节”状态及等待时长；已结束的课程会跳过。填写时间时则以指定日期和时间计算。

全学期排行统计当前 ICS 中的历史和未来课程，包括可确定次数的有限重复课程。解析异常的课表、无结束条件的重复课程，以及展开超过 10000 次的超大课表会被跳过；排行榜会用文字提示统计可能不完整。普通日期和周排行可以查询没有结束条件的重复课程。

## ❓ 如何获取 .ics 文件或 WakeUp 口令？

*   **.ics 文件**：将你的课表导入课表软件（如 **Wakeup课程表** 或类似应用），然后从软件的设置中选择“导出”，并导出为日历文件（通常文件后缀为 `.ics`），即可获得所需文件。
*   **WakeUp 口令**：在 **WakeUp课程表** 应用中，选择“分享课表”，然后选择“分享给好友”，复制生成的口令即可。

## ⚙️ 文件结构

* 顶层文件
    * `main.py` — 插件入口与主逻辑，处理命令路由与核心流程。
    * `constants.py` — 常量与配置默认值（字符串、路径、默认选项等）。
    * `ics_parser.py` — 解析 `.ics` 日历文件与 WakeUp 分享口令，归一化为内部课程数据结构。
    * `schedule_helper.py` — 与课程调度/时间计算相关的辅助函数（判断进行中/下一节、时区处理、节次计算等）。
    * `image_generator.py` — 将课程数据渲染为图片（个人课表、群友总览、排行榜等）。
    * `data_manager.py` — 数据存取与持久化（用户绑定信息、导入的日历内容等）。
    * `metadata.yaml` — 插件元信息（名称、版本、作者、权限等）。
    * `requirements.txt` — 项目依赖清单。
    * `README.md` — 本说明文档。
    * `LICENSE` — 项目许可证文件。
