# 本地测试与 Bot 验收

在安装 `requirements.txt` 的 Python 环境中运行：

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

自动测试使用模拟的 AstrBot 接口、临时文件和人工构造的课表，覆盖命令逻辑与真实 ICS 解析，不代表已完成实际 Bot 验证。

## 在测试 Bot 中验收

使用测试群和测试账号，发送 `/绑定课表` 后上传 `fixtures/query_demo.ics`。此文件只有示例课程，没有真实用户信息。可再由第二位测试成员绑定同一份课表，以验证 @查询。

| 操作 | 单个测试成员的预期结果 |
| --- | --- |
| `/查看课表 2026-10-13` | 显示 14:00–15:30 的示例实验课，历史查询也能显示 |
| `/查看课表 2026-10-13 @另一位测试成员` | 图片使用被查询成员的昵称和课程 |
| `/群友在上什么课 2026-10-13 14:30` | 示例实验课显示“进行中”，剩余 60 分钟 |
| `/群友在上什么课 2026-10-13 15:30` | 当天已无正在上或接下来要上的课程 |
| `/群友在上什么课 2026-10-13` | 以真实当前时刻查询该日正在上或后续课程，等待时长从现实当前时间计算；若课程已经全部结束则显示无课 |
| `/全学期上课排行` | 每位绑定该样例的成员共 6 次课程、6 小时 30 分钟 |

上周、本周、下周均以执行命令时的上海日期计算，周一到周日为一周。样例在 2026 年 10 月 12–18 日执行时，预期如下：

| 命令 | 每位绑定样例的成员 |
| --- | --- |
| `/上周上课排行` | 2 次课程、2 小时 |
| `/本周上课排行` | 2 次课程、2 小时 30 分钟 |
| `/下周上课排行` | 1 次课程、1 小时 |

还应确认无参数的 `/查看课表` 和 `/群友在上什么课`、两个原有明日查询命令仍能使用；无效日期、无效时间、多个 @成员和未绑定成员返回文字提示。

全学期排行按当前 ICS 中的所有课程统计，重复规则必须有结束日期或次数。异常或过大的课表会被跳过并提示排行可能不完整。
